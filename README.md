# منشئ — Website Builder

منصة عربية تجريبية لإنشاء المواقع وتحرير HTML ومعاينته ونشره بعد التحقق.

## المجلدات

- `css/` تنسيقات الواجهة.
- `js/` منطق التخزين والمصادقة والمحرر والنشر.
- `assets/` مكان الصور والخطوط مستقبلًا.
- `data/` قوالب المشاريع المستقبلية.

## التشغيل

افتح `index.html` عبر خادم محلي لأن التطبيق يستخدم JavaScript Modules:

```bash
python3 -m http.server 8080
```

ثم افتح `http://localhost:8080`.

> تسجيل Google والنشر الحاليان تجريبيان في الواجهة. للإنتاج يجب إضافة OAuth وخادم آمن وقاعدة بيانات وخدمة نشر حقيقية.
